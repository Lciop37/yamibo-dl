# 百合会小说漫画帖下载器（油猴脚本）

一个浏览器脚本，给 bbs.yamibo.com 的帖子页加上「下载本帖」按钮、板块页加上「批量下载」按钮：

- **漫画帖** → 抓取帖内全部图片（含附件原图），打包成 ZIP 一键下载
- **小说帖** → 导出 TXT 或 EPUB，自动剔除引用、签名、评分、楼层目录等杂质；EPUB 会把帖内插图下载后嵌入书中，阅读器离线可读
- **批量** → 在板块列表页勾选多个主题，排队自动下载

脚本完全在浏览器本地运行，不经过任何第三方服务器；需要安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）浏览器扩展。

## 安装（约 1 分钟）

1. **装油猴扩展**：Edge 或 Chrome 打开扩展商店，搜索 **Tampermonkey** 安装（Edge 商店若搜不到，去 tampermonkey.net 官网点浏览器图标安装）。
2. **一键安装脚本**：用浏览器打开安装链接 [yamibo-dl.user.js](https://raw.githubusercontent.com/Lciop37/yamibo-dl/main/yamibo-dl.user.js)，页面会自动跳转到 Tampermonkey 的安装界面，点「安装」即可。
   - 若打开后没有弹出安装界面，改用手动导入：点浏览器右上角油猴图标 →「管理面板」→「工具」→「导入文件」，选择下载好的 `yamibo-dl.user.js`；或「添加新脚本」把文件内容整体粘贴后保存。
3. **先用你的账号登录** https://bbs.yamibo.com ，然后打开任意帖子页或板块页，右下角出现粉色按钮即安装成功。

> 脚本复用你浏览器的登录状态：**回复可见图、阅读权限帖、附件**都必须是你这个账号在论坛上能看到的才能下载。

## 使用

### 单帖：帖子页右下角「下载本帖」

| 选项 | 说明 |
|---|---|
| 漫画(图包) | 全部图片打包为一个 ZIP |
| 小说(TXT/EPUB) | 可选「全部楼层 / 只看楼主」；TXT 里图片位置标注 `[图](链接)` 便于对照 |
| 逐张直下 | 超大漫画帖可改为逐张下载到 `yamibo/帖名/` 文件夹（首次需允许浏览器「下载多个文件」） |
| 页数上限 | 默认最多 30 页，可在面板里调整 |

### 批量：板块列表页右下角「批量下载」

自动列出本页全部主题，全选或逐条勾选，每帖标好「漫画/小说」类型，点开始后排队的帖自动逐个下载，失败的自动跳过并在面板显示进度。

## 常见问题

- **没看到粉色按钮？** 确认油猴已启用、脚本已安装且开启；刷新页面；打开 F12 控制台应能看到 `[yamibo-dl] vX.X.X 已加载` 字样，没有则安装未生效。
- **下载的图片缺了一部分？** 大概率是账号权限不够（回复可见/阅读权限），先在网页上确认你能看到它们。
- **下载中途提示 405/403？** 论坛的反爬机制偶发拦截，脚本会自动等待重试，面板卡住稍等即可。
- **怎么更新到新版？** 装了本仓库链接的版会自动检查更新；手动版则在油猴「管理面板」→ 脚本名上右键 →「检查更新」，或重新导入新文件。

## 提醒

站内多为民间汉化/翻译存档，导出内容**仅供个人离线阅读**，请遵守论坛规则，不要二次传播。作者仅为方便自用编写此脚本，如造成任何不适可联系删除。
